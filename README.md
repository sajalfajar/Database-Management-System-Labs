# Database Management System Labs

This repository contains my Database Management System (DBMS) lab tasks and practice queries in SQL.

## About

The labs in this repository were completed while learning how to design, create, and query relational databases. Each lab is kept separate so it is easy to find.

## Topics Covered

- Introduction to databases and DBMS
- Creating databases and tables (DDL)
- Inserting, updating, and deleting data (DML)
- Querying data with SELECT, WHERE, ORDER BY, and GROUP BY
- Constraints (primary key, foreign key, unique, not null)
- Joins (inner, left, right)
- Aggregate functions
- Subqueries
- Views
- Normalization
